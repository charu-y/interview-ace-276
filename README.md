# InterviewPilot — AI Mock Interview Bot

Build "InterviewPilot" — a mock interview app:

- Screen 1: pick a role (3 cards: SDE Intern, Data Analyst, 

  Frontend Developer)

- Screen 2: chat interface — AI asks questions one at a time, 

  user types answers in a text box, a timer shown per question

- Screen 3: report card — score out of 10 per question, 

  2 strengths, 2 weaknesses, one model answer for the weakest response

- Professional look: navy + white color scheme, clean fonts

Use dummy data first. I will connect the AI in the next step.
